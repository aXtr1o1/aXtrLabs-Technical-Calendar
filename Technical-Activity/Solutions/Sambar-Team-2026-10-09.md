## Sambar Team Proposed Solution :

# Issue Tracking Portal :

Create an Issue Tracking Portal (something similar to Microsoft Teams, can even use Discord)

Give options to send messages inside the portal, where we can use slash commands to post structured messages (instead of mail)

Slash commands: /issue , /discussion , /decision , /announcement , /document

Each command has its own fields (issue: severity, assignee, status, root cause, resolution, attachments)

Issues follow a status flow (New -> Assigned -> In Progress -> Resolved -> Closed), and every change is logged

All the issues, discussions, decisions and documents are stored in a VDB, and users can retrieve them using an AI (even if they use different words for the same problem)

Role based access, so HR, security and client data are visible only to the allowed people
